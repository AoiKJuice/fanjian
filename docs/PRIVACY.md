# 隐私说明

资料、评分修改、收藏、隐藏、推荐历史和反馈保存在本机 SQLite。产品没有云账户和跨设备同步。

AniList 和 Bangumi 导入只发送用户主动填写的用户名。Bangumi Access
Token 只用于当次请求，不写入 SQLite。MAL XML 在本机解析。推荐解释不显示
训练数据中的用户名或其他可识别信息。

删除资料会通过数据库外键同时删除该资料的评分、收藏、隐藏、推荐历史和反馈。导出文件可能包含完整观看记录，用户需要自行选择安全的保存位置。

当前自动检查已经覆盖依赖漏洞、资料级联删除、API contract 和 axe-core。
以下项目仍需人工执行并公开记录：

- 独立的安全审查；
- 屏幕阅读器人工测试记录。

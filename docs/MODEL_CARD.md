# 模型卡

## 生产模型

- 名称：surprise-weighted positive UserKNN with residual ranking
- 版本：`surprise_weighted_userknn-series-balanced-rank-v3`
- 训练评分：134,143,996
- 训练用户：989,203
- 评分作品：16,300
- 当前作品目录：30,677 个唯一 MAL ID

API 从 `model-selection.json` 读取生产选择。服务缺少真实模型文件时停止启动。测试代码只有在设置 `ANIME_USE_DEMO=1` 后才加载虚构样本。

本版本只使用 User Animelist 的逐用户评分训练。Bangumi 评分只显示在界面中，不参与排序。

## 选择依据

500 名用户参加确定性留出评测，随机种子为 `20260728`。每名用户保留 20% 评分，最多 20 条；8 分及以上作品算作相关结果。评测从 KNN 邻居中排除目标用户。

| 模型 | NDCG@10 | Recall@20 | HitRate@10 | LowPop NDCG@10 | 长尾覆盖 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Bayesian Popularity | 0.01166 | 0.02518 | 0.106 | 0.00758 | 0.00077 |
| mean-centered UserKNN | 0.09696 | 0.13940 | 0.524 | 0.07782 | 0.00245 |
| surprise-weighted UserKNN | **0.10131** | **0.14577** | **0.564** | **0.08206** | **0.00322** |

surprise-weighted UserKNN 的 NDCG@10 相对提高 4.49%，用户级 bootstrap 差值 95% 区间为 `[-0.00573, 0.01434]`。区间跨过 0，因此不能解释为显著准确率胜出。

长尾覆盖提高 31.25%，LowPop NDCG@10 提高 5.45%。它通过项目预先规定的第二组条件：总体 NDCG@10 不下降超过 1%、长尾覆盖提高至少 15%、LowPop NDCG@10 不下降超过 2%。

## 生产参数

- 共同评分门槛：20
- 相似度收缩：`overlap / (overlap + 10)`
- 正相似邻居数：50
- surprise 混合系数：1.0
- 不确定性惩罚：0.5
- 候选邻居支持门槛：15
- 有效样本量门槛：3
- 作品训练评分门槛：20

用户相似度使用标准化评分残差、IUF 和评分事件稀有度。候选排序同样使用邻居对候选作品的标准化残差，不再使用原始评分减用户均分。作品偏差只用于残差校准，不加回候选分数。

平台均分、标签、简介和评论不参与核心排序。格式、年份、成人内容和续作选项只删除候选。

## 输出解释

API 返回邻居支持数、有效样本量、邻居评分分布和三个高区分度共同评分。接口不会返回训练用户名。

`affinity` 使用固定种子 `20260729` 的 500 名留出用户、33,199 个候选分数拟合经验分位数。数值表示该候选分数在留出查询中的相对位置，不表示观看后喜欢的概率。分数样本的中位数为 0.1475。

## 当前限制

- 当前评分数据早于完整作品目录，新作品只有在评分来源包含足够证据后才进入协同过滤候选。
- 现有目录没有完整前作关系边，尚不能计算续作顺序错误率。
- 显式评分包含观看选择偏差。
- 当前公开模型不包含 Bangumi15M 和巴哈姆特逐用户评分。
- 尚未完成 8 人可用性测试、SUS 和真实设备 Web Vitals。
